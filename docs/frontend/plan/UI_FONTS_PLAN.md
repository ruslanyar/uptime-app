# Manrope и JetBrains Mono для UI

## Решение

Использовать Manrope для заголовков, основного текста, имён, кнопок и форм.
JetBrains Mono использовать для существующих моноширинных надзаголовков,
коротких подписей, футера и бейджа, а также отображаемых email в профиле
и меню пользователя. Поля ввода остаются на Manrope.

## Подключение

- Подключить оба variable-шрифта через `next/font/google` в корневом layout
  с `subsets: ['latin', 'cyrillic']`, `display: 'swap'` и `style: 'normal'`.
- Добавить CSS-переменные `--font-manrope` и `--font-jetbrains-mono` на `html`,
  сохранив класс `dark`.
- Связать `--font-sans` и `--font-mono` в Tailwind-теме с соответствующими
  переменными и системными резервными шрифтами.
- Сохранить размеры, насыщенность, интервалы и классы `uppercase`.
- Описать типографику и необходимость доступа к Google Fonts при сборке в README.

## Проверка

- Lint, форматирование, TypeScript, существующие тесты и production build
  с `NEXT_PUBLIC_API_URL`.
- Осмотреть вход, регистрацию, профиль и дашборд на мобильной и десктопной
  ширине: кириллицу, переносы, короткие подписи и длинные email.
- Проверить применение обоих шрифтов и загрузку их файлов с домена приложения.

## Границы

Меняется типографика существующих экранов. API, авторизация и зависимости
остаются прежними. Новые элементы мониторинга не добавляются.

## Результат

- Оба шрифта подключены; отображаемые email используют `font-mono`.
- Lint, форматирование, TypeScript и production build прошли.
- Vitest: 40 тестов; проверки Tailwind через `node:test`: 2 теста — успешно.
- Существующий Playwright-сценарий `dark UI stays responsive with long account details`
  прошёл на localhost с реальными API и PostgreSQL. Проверены экраны регистрации,
  входа, профиля, дашборда и меню на ширинах 375 и 1440 px, включая длинные email.
  Скриншоты осмотрены и сохранены в игнорируемом `test-results/`.
- В Chromium на production-сборке подтверждены Manrope для основного текста,
  JetBrains Mono для `font-mono` и загрузка четырёх WOFF2-файлов с домена приложения
  без обращений браузера к Google Fonts.
