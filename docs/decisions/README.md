# Архитектурные решения

ADR храните в Git под именами `NNNN-short-name.md`.
Используйте [шаблон](../templates/adr.md) и
[правила ведения ADR](../rules/documentation.md#архитектурные-решения).

При добавлении решения внесите сюда ссылку с номером, названием и статусом.
Действующие ограничения размещайте в `docs/rules/` и связывайте с решением.
