# Редактирование и удаление мониторов

## Результат и порядок работы

Редактирование URL и интервала, окончательное удаление с подтверждением и
`updated_at` в БД и API. Пользователь управляет только своими мониторами.

Рабочая ветка: `feat/monitor-edit-delete`, от актуальной `origin/main`.
Каждый блок — один логический коммит. Реализация → проверки → самостоятельное
ревью → незакоммиченный дифф для ревью пользователя в редакторе → исправления
и повторные проверки → одобрение пользователя → отметка чекбоксов и коммит.
До одобрения блока следующий блок не начинается. PR и слияние не входят в задачу.

## Проверки и решения

Backend: `sh scripts/check-sqlc.sh`, `go test ./... -count=1` с реальной тестовой
PostgreSQL, `go vet ./...`, `go build -o bin/api ./cmd/api`. После изменения CORS:
HTTPS-проверка с `AUTH_BROWSER_CHECK=1` по README.

Frontend: `npm run format:check`, `npm run lint`, `npm run typecheck`, `npm test`,
production build и Playwright с реальными API и PostgreSQL. Backend-интеграции
и frontend E2E запускать последовательно: они используют общую тестовую БД.

updated_at пока не отображается в карточке. При одновременном редактировании
действует последнее успешное сохранение. Перед выпуском применить миграцию,
затем обновить API и frontend; развёртывание не входит в текущую задачу.
