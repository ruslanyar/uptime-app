# Uptime App

Два независимых проекта для дальнейшей разработки сервиса мониторинга uptime.

```text
backend/
  cmd/api/       # Точка входа Go-приложения
  internal/app/  # Пакет для будущей инициализации приложения
  go.mod
frontend/
  src/app/       # Next.js App Router
  public/        # Статические файлы
  package.json
```

Инструкции запуска и проверки находятся в README каждого проекта.

На этом этапе создан только каркас. Мониторинг сайтов, API, база данных,
авторизация и интеграция между проектами ещё не реализованы.
