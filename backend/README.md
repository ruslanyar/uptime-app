# Backend

Минимальный Go-модуль без внешних зависимостей и бизнес-логики.

Требуется Go 1.27+.

- `cmd/api/main.go` — пустая точка входа будущего сервиса.
- `internal/app` — место для будущей инициализации приложения.

Из директории `backend`:

```sh
go run ./cmd/api
go build -o bin/api ./cmd/api
go test ./...
go vet ./...
```

Сейчас точка входа сразу завершает работу. HTTP-сервер ещё не реализован.
