# Хуки Codex

- Требуются Git, Node.js, `gofmt`, Go toolchain проекта и зависимости фронтенда
  (`npm ci` из `frontend/`). Хуки не устанавливают зависимости.
- Подтвердите доверие к проекту и определениям через `/hooks` в Codex CLI;
  после изменения определений подтвердите его повторно. Если конфигурация
  не перечиталась, начните новую сессию.
- Перед новой задачей обновите локальную `origin/main`: проверка OpenAPI
  учитывает также коммиты ветки относительно merge-base с этой ссылкой.
- Используйте отдельные рабочие копии для параллельных сессий:
  снимки форматирования не различают одновременные правки одних файлов.
- `SessionStart` сообщает ветку, наличие незакоммиченных изменений и HTTP-статусы
  локальных frontend/API на стандартных адресах из корневого README. Он работает
  также в Plan mode; серверы не запускает, авторизацию и состояние БД не проверяет.
- В Plan mode форматирование и OpenAPI пропускаются. Повторная ошибка OpenAPI показывается
  без нового продолжения; это не означает успешную проверку.
- Снимки в `.dev/codex-hooks/`, оставшиеся после прерывания, можно удалить
  при закрытых сессиях Codex.

Из корня репозитория:

```sh
node --test .codex/hooks/codex-hooks.test.mjs
sh .agents/skills/openapi-contract/scripts/check-openapi.sh
```

Проверка генерации OpenAPI не заменяет проверку соответствия аннотаций
поведению API по навыку `openapi-contract`.
